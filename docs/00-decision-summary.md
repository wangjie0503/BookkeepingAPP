# 00 已确认需求总览

这是本轮需求澄清后的最终结论，供快速核对。

## 产品定位
- 个人自用
- 只记录支出
- 目标是看每一期生活费花到哪里
- Flutter 跨平台
- Windows Desktop 纳入 MVP，作为电脑端快速开发/验收平台，也可独立日常使用
- Android 纳入 MVP，必须可以构建安装
- iOS 保持兼容，后续具备 macOS/Xcode 环境后做构建验证
- 本地 SQLite，不做服务器
- MVP 不做设备间同步，因此 Windows 与手机各自保存独立本地数据

## 一笔支出
- 金额
- 一级分类
- 二级分类
- 消费时间
- 不记录事件、备注、商家、地点、图片、支付方式
- 金额 > 0，最多 1 位小数
- 数据库存“角”的整数
- 默认当前时间，可改过去，不可选未来
- 可编辑
- 可删除，删除前二次确认

## 分类
- 两级分类
- 首次安装内置默认分类
- 一级、二级名称全局都不能重复
- 停用代替物理删除
- 停用一级分类不改变子分类自身启用状态，只是在新增支出时整体不可见
- 分类改名后历史账单和统计都使用新名称
- 二级分类可以移动到其他一级分类，历史统计跟着最新父级变化
- MVP 固定排序，新分类追加末尾；预留 sort_order

## 预算
- 有默认月预算
- 每个生活费周期拥有独立预算快照
- 某一期可以单独修改预算
- 修改默认预算不影响历史周期
- 不做预算系统通知

## 生活费周期
- 不是自然月
- 当前每月 25 日发生活费
- 例如 2026-08-25 ~ 2026-09-24 称为“2026 年 8 月”
- 默认按生活费周期查看
- 同时允许自定义日期范围
- 自定义日期范围不显示预算、剩余和预算使用率
- 历史周期不能因未来规则修改而变化
- 修改周期起始日后的过渡周期完整行为不进入 MVP

## 统计
- 总支出
- 预算 / 已消费 / 剩余或超支 / 使用率（完整周期）
- 一级分类环形图
- 一级分类可展开查看二级分类合计
- 每日消费趋势图

## 数据导出
- MVP 做 CSV 导出
- 暂不做完整备份/恢复
- 暂不做云备份
- 暂不做 CSV 导入

## 明确不做
- 收入
- 转账
- 多账户
- 多币种
- 登录/后端
- 多端实时同步
- 系统通知
- 分类拖拽排序
- AI 分析
- 备注/商家/地点/图片/OCR
