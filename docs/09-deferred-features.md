# 09 后续扩展，不属于 MVP

下面功能明确保留扩展空间，但第一版不要实现。

## 数据安全与迁移
- 完整 JSON/数据库备份
- 全量恢复
- 换机迁移
- 云备份
- iCloud / Google Drive
- 备份合并
- CSV 导入

## 分类体验
- 拖拽排序
- 使用频率排序
- 分类图标/颜色自定义

## 预算
- 系统通知
- 预算 80% / 100% 提醒
- 自定义提醒阈值
- 更复杂的预算预测

## 生活费周期
未来允许修改生活费发放日时：
- 历史周期绝不修改
- 新规则从上一周期结束后的下一天开始
- 允许过渡周期长短不同
- 不允许重叠或空档

**过渡周期预算如何确定尚未纳入 MVP，不要自行实现。**

## 财务能力
- 收入
- 退款
- 转账
- 多账户
- 信用卡
- 资产负债
- 多币种
- 汇率

## 记录丰富度
- 消费事件
- 备注
- 商家
- 地点
- 图片
- 小票 OCR

## 云端能力
- 登录注册
- 后端 API
- 多设备实时同步
- Web 管理端

## 智能分析
- AI 月度总结
- 异常支出识别
- 消费建议

任何扩展功能开始前都应重新做需求确认，不能因为“顺手”而塞进 MVP。
