# 01 产品需求说明

## 1. 产品目标

帮助用户持续记录日常支出，并回答：

> 这一期生活费一共花了多少？主要花在哪些一级分类和二级分类？哪几天花得特别多？

核心用户只有本人。

## 2. 平台目标

- 使用 Flutter 开发，一套业务代码覆盖桌面和移动端。
- **Windows Desktop 是 MVP 必须支持的平台**：开发过程中可直接在电脑运行，快速验证四个核心页面和业务逻辑，同时也可以作为独立桌面记账 App 使用。
- **Android 是 MVP 必须支持的平台**：最终必须可以构建 APK 并安装验证。
- iOS 保持代码和依赖兼容；由于 iOS 构建需要对应 Apple 开发环境，不作为当前 MVP 的硬性构建验收项。
- 核心功能在 Windows 和 Android 上都必须离线可用。
- MVP 不做跨设备实时同步：Windows 与手机各自使用本地 SQLite 数据库，数据彼此独立。

## 3. 核心功能

### 3.1 记一笔

每笔支出只记录 4 个核心字段：

- 金额
- 一级分类
- 二级分类
- 消费时间

不记录消费事件、备注、商家、地点、支付方式、图片。

### 3.2 支出列表

记录并展示每笔消费，按消费时间倒序排列。

支持：
- 默认查看当前生活费周期
- 自定义起止日期
- 编辑历史支出
- 删除历史支出，删除前二次确认

### 3.3 分类管理

支持：
- 新增一级分类
- 新增二级分类
- 修改名称
- 停用/恢复分类
- 将二级分类移动到其他一级分类下

分类变化必须立即反映到“记一笔”和统计中。

### 3.4 概述统计

默认查看当前生活费周期。

完整生活费周期展示：
- 本期预算
- 已消费
- 剩余金额 / 超支金额
- 预算使用率
- 一级分类环形图
- 一级分类金额列表
- 展开一级分类后展示各二级分类总金额
- 每日消费趋势图

自定义日期范围展示：
- 总支出
- 一级分类统计
- 二级分类明细
- 每日消费趋势

自定义范围不显示预算相关信息。

## 4. 预算与生活费周期

- 不是自然月记账。
- 生活费发放日目前为每月 25 日。
- 一个周期示例：2026-08-25 至 2026-09-24。
- 周期名称按“发钱月份”命名，上例称为“2026 年 8 月”。
- 存在默认月预算。
- 新周期第一次生成时，用默认月预算生成该周期自己的预算快照。
- 每个周期预算可独立修改。
- 后续修改默认预算，不影响已经存在的历史周期。

## 5. 数据导出

MVP 支持 CSV 导出用于查看和二次分析。

暂不支持：
- 完整备份
- 恢复
- 云同步
- CSV 导入

## 6. 设计原则

- 自用优先，不追求“大而全”。
- 记一笔必须尽可能少操作。
- 统计口径必须稳定、可解释。
- 历史支出不能因为分类被停用而丢失。
- 允许用户未来重新整理分类体系，因此改名和移动会作用到历史统计。
