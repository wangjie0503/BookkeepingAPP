# 个人记账 App

一个围绕“**生活费到底花到哪里了**”设计的个人离线记账 App。

## 产品定位

这不是完整财务软件。第一版只做支出记录、分类管理、生活费周期预算、支出去向统计和 CSV 导出。

主要使用者只有本人，因此优先级为：

1. 记账足够快
2. 数据长期稳定
3. 统计口径清晰
4. 本地可离线使用
5. Windows 电脑上可以快速运行和验收
6. 架构方便以后扩展

## 平台目标

同一套 Flutter 代码同时面向：

- **Windows Desktop：MVP 必须支持，作为开发阶段的快速运行/验收平台**
- **Android：MVP 必须支持，最终需要可构建并安装到手机**
- **iOS：代码保持兼容，后续在具备 macOS/Xcode 环境时完成真机构建验证**

Windows 和手机使用同一套业务代码、页面组件和数据模型，但由于 MVP 不做云同步，**每台设备拥有各自独立的本地 SQLite 数据库**。电脑端主要用于快速开发、功能验收，同时也可以作为独立桌面记账 App 使用。

## 主界面

四个主入口：

1. **记一笔**：快速新增支出
2. **支出列表**：查看、筛选、修改、删除历史支出
3. **分类管理**：管理一级分类和二级分类
4. **概述统计**：查看预算、支出去向和每日消费趋势

视觉参考：`docs/assets/ui-reference.png`

## MVP 技术方案

- Flutter / Dart
- SQLite + Drift
- Riverpod
- fl_chart
- CSV 导出
- 本地离线使用
- Windows + Android 双平台 MVP
- 自适应桌面/移动布局
- Material 3

## 给 Codex 的启动方式

把整个目录放到项目根目录后，将 `CODEX_START_PROMPT.md` 的内容交给 Codex。

Codex 应先阅读文档、产出实施计划，再开始写代码，不要一次性把所有功能同时实现。
